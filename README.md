# Hafizh Abrizam — Personal Portfolio

Website portofolio bilingual (Bahasa Indonesia / English), dibuat dengan HTML, CSS, dan JavaScript biasa.

## Cara menjalankan
1. Ekstrak folder `hafizh_personal_portfolio`.
2. Buka `index.html` menggunakan browser.
3. Untuk mengganti foto, masukkan foto pribadi ke folder `assets` dan beri nama `profile.jpg`.
4. Buka ulang / refresh halaman.

## Sebelum dipublikasikan
- Ganti `your.email@example.com` di `index.html` dengan email aktif.
- Periksa kembali deskripsi proyek dan skill agar sesuai dengan pengalaman sebenarnya.
- Tambahkan tautan GitHub / LinkedIn / Instagram jika ingin ditampilkan.
- Tambahkan screenshot proyek di bagian Projects jika tersedia.

## Publikasi gratis dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `hafizh-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website.

Catatan: konten portofolio merupakan draft awal. Pastikan semua informasi, kemampuan, dan proyek telah diperiksa sebelum dibagikan secara publik.
